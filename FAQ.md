# Frequently asked questions

## Can I download CombatGlass?

No. This is a public development preview. No executable, installer or archive
has been published.

## Does CombatGlass support AION 2 Global today?

Not yet. Protocol support is awaiting live validation. Regional assumptions are
not being presented as Global compatibility.

## Is CombatGlass open source?

No. CombatGlass is closed-source freeware. This public repository contains the
product presentation, privacy/security information and original brand assets.

## Is it free?

Yes. The initial product has no subscription, premium tier, advertisement,
account or feature paywall. A quiet optional donation link may be added later.

## Does it read game memory or inject anything?

No. The architecture forbids opening the AION 2 process, memory access, DLL/code
injection and graphics hooking.

## Does it modify or send packets?

No. Capture is receive-only by design. CombatGlass does not transmit, modify,
drop, delay or proxy game packets.

## Does it automate gameplay?

No. CombatGlass does not automate skills, rotations, targeting, movement or
input and does not create gameplay macros.

## Does it upload fights or require an account?

No. Version 0.x has no account, CombatGlass backend, telemetry or automatic
upload.

## Will I be banned for using it?

No third-party project can responsibly promise that. Passive architecture lowers
technical interaction with the game, but CombatGlass is not endorsed by NC and
users remain responsible for applicable rules and terms.

## Why Npcap?

Npcap is the current candidate for passive Windows capture. It will not be
silently installed or bundled unofficially. Demo Mode does not need it. Exact
privilege requirements will be validated against current Npcap configurations.

## Why are some values “Unavailable”?

CombatGlass only displays metrics supported by verified data. Unknown fields are
not guessed and are not shown as zero.
