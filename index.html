FAQ

Straight answers before installation.

Can I download CombatGlass now?

No. This is a public development preview; no executable, installer or portable archive is published.

Does CombatGlass need an account or send telemetry?

No. The v0.x product is local-only, without accounts, telemetry, cloud uploads or a licence server.

Does it read game memory or automate play?

No. The architecture forbids memory access, injection, packet modification, proxying and input automation.

Is using a passive meter guaranteed safe for my account?

No third party can promise that. Rules and enforcement can change; review the game terms and use third-party tools at your own risk.
